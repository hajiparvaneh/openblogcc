# openblogcc

Preview / example site for **[openblog.cc](https://openblog.cc)**.

This repository is **not** the blogging template. It is one live example of OpenBlog in use (including community-oriented features that belong only on the preview site).

## Template (clone this instead)

To start your own blog, use the main template:

**https://github.com/hajiparvaneh/openblog**

```bash
# Use “Use this template” on GitHub, or:
git clone https://github.com/hajiparvaneh/openblog.git my-blog
cd my-blog
npm install
npm run dev
```

## Local (this preview repo)

```bash
npm install
npm run dev
```

Community features (scoring, OAuth Worker, leaderboard) live here only — not in the main template.

## Docs

Product structure is documented in the OpenBlog Confluence space (two-repo model: `openblog` + `openblogcc`).
